Install

Three commands, from source.

A Windows installer and the desktop launcher are coming; until then this is the developer path.

1 · Build

One Rust binary; the embedding models are checked by hash.

cargo build --release

2 · Library

Index a folder you allow. Skip it if you only want memory.

footnote --db kb.db index --root ./docs --allow ./docs

3 · Memory

Memory, its hooks and /remember in every agent found.

footnote install --memory
