What it is

A memory layer you can audit.

Local

Your corpus is one SQLite file and one search index on your own disk, searched by embedding models that run on your CPU. Nothing is sent anywhere.

Cited

Each hit is bound to the exact bytes it came from. When the file has changed since, the hit says stale and your agent knows not to rely on it.

Read-only for agents

An agent can recall and fetch from the corpus. Writing takes a command from you; a proposal sent over MCP is refused, and every call is appended to a tamper-evident audit log.

How it works

Five steps, none of them a language model.

  1. IndexMarkdown, text and PDF are split into chunks and hashed. Originals are never modified.
  2. ShortlistA BM25 index finds candidates for every word of the question, stemmed, accents folded.
  3. Re-scoreTwo local embedding models compare meaning. Vectors are stored as 8-bit integers, with ranking differences within 0.0004 nDCG in our tests.
  4. FuseThe two scores are blended with fixed weights. No tuning at query time.
  5. CiteEach result carries path, line, hash, revision and freshness, checked at read time.

Install

One command connects Claude Code, Codex and Gemini.

Index a folder, then connect your agents

# build from source (Rust 1.85 or later)
git clone https://github.com/bobcat88/footnote && cd footnote && cargo build --release
export PATH="$PWD/target/release:$PATH"
mkdir -p ~/.footnote
footnote --db ~/.footnote/knowledge.db index --root ~/notes --allow ~/notes
footnote --db ~/.footnote/knowledge.db install

Or add it by hand

# Claude Code
claude mcp add footnote -- "$PWD/target/release/footnote" --db "$HOME/.footnote/knowledge.db" mcp
# Codex CLI
codex mcp add footnote -- "$PWD/target/release/footnote" --db "$HOME/.footnote/knowledge.db" mcp

Commands shown use a POSIX shell and set up lexical search. For hybrid search, Windows instructions and other MCP hosts, see the README on GitHub.

Trust

Built so that you can check it.

  • No network. The tool makes no outbound requests; this page loads nothing from a third party, fonts included.
  • Read-only over MCP. Agents recall and fetch. Writes need an explicit command from you.
  • Private by construction. State lives in a user-only folder; the daemon speaks over a local socket with a mutual HMAC handshake.
  • Tamper-evident log. Every call is appended to a hash-chained, MAC-signed audit log you can verify offline.
  • Untrusted by default. Retrieved text is labelled as data, never as instructions.
  • Receipts, not claims. Every number on this page comes from a stored run you can reproduce.
